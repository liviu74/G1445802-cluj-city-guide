
# Cluj-Napoca City Guide (CPU4104 - Web Development)

**Student ID:** G1445802  
**Project Name:** Cluj-Napoca City Guide Website

## Project Overview
This website is a responsive, interactive city guide for **Cluj-Napoca, Romania**, built using semantic HTML5, CSS3, and vanilla JavaScript. Visitors can browse landmarks, parks, museums, and cultural sites, search and filter attractions, save favourites, and send contact messages.

## Folder Structure
- `pages/` – HTML5 pages (`index.html`, `attractions.html`, `favourites.html`, `about.html`, `contact.html`)
- `css/` – Stylesheet (`style.css`) with Flexbox layout and responsive design
- `js/` – JavaScript (`script.js`) for search, filtering, modal details, favourites (`localStorage`), and form validation
- `media/` – Attraction images (`.jpg`)
- `README.md` – Project documentation and instructions

## How to Run the Project
1. Download or clone this repository.
2. Open the `pages/` folder.
3. Double-click **`index.html`** to open the website in your web browser.
